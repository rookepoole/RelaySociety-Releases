# Changelog

This file records public release-channel and documentation changes. Product changes are described on each GitHub release page.

## Unreleased

- Expanded the repository into the public Relay Society beta portal.
- Added exact setup, capability, security, support, update, rollback, and release-integrity documentation.
- Added a machine-readable current-release catalog and automated repository validation.
- Added structured bug and feature-request templates.

## v0.3.69 beta — 2026-08-21

- Published the accepted unsigned schema-38 Windows x64 and static Linux x64 packages.
- Added the first production governed-council slice across the Rust runtime, Control Room, 85-operation OpenAPI contract, and both generated clients.
- Qualified distinct council principals, conflict exclusion, vote revision, deterministic close, minority-argument retention, integrity verification, and backup/restore preservation.
- Retained explicit limits: bearer authorization is not one-human-one-account proof, and broader governance modes remain open.
- Published exact SHA-256 checksums and the immutable manual-update manifest.

[Release notes and downloads](https://github.com/rookepoole/RelaySociety-Releases/releases/tag/v0.3.69)

## v0.3.68 beta — 2026-08-20

- Published the accepted unsigned Windows x64 and static Linux x64 packages.
- Published exact SHA-256 checksums and an immutable machine-readable update manifest.
- Established GitHub Releases as the canonical public binary channel.
- Retained manual, user-confirmed updates with automatic execution disabled.

[Release notes and downloads](https://github.com/rookepoole/RelaySociety-Releases/releases/tag/v0.3.68)
